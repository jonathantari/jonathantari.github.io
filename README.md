# garage.jonathantari.com

Hub for public projects.

- `index.html` — the 8-bit garage landing page (the box links to Turnaround)
- `turnaround/` — the Turnaround site (copied from the `site-2` repo, which is deprecated)
- `play/` — test build of the garage game (not linked from the landing page). Built in the private `garage-game` repo and copied here by its `tools/publish.sh`; don't edit it here

Any other public repo with GitHub Pages turned on also appears at `garage.jonathantari.com/<repo-name>`.
