# garage.jonathantari.com

Hub for public projects.

- `index.html` + `game/` — the 8-bit garage landing page, with the garage game hidden inside it (the box links to Turnaround). Built in the private `garage-game` repo and written here by its `tools/publish.sh`; don't edit them here
- `turnaround/` — the Turnaround site (copied from the `site-2` repo, which is deprecated)

Any other public repo with GitHub Pages turned on also appears at `garage.jonathantari.com/<repo-name>`.
